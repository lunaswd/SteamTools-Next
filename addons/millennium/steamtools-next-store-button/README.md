# SteamTools Next Store Button

This Millennium theme adds a SteamTools Next import button below the purchase or play action on Steam product pages.

## Install

1. Install Millennium for the Steam desktop client and close Steam.
2. Extract this ZIP and copy `steamtools-next-store-button` into `<Steam folder>/millennium/themes/`.
3. Start Steam and enable **SteamTools Next Store Button** in Millennium's Themes page.
4. Start SteamTools Next once so Windows registers its `steamtoolsnext://` link handler.

The button appears on product pages where Steam renders a purchase or play action. Clicking it opens SteamTools Next for confirmation. The app then uses the selected Steam directory and current catalog import settings.

This adds an entry to the local SteamTools Lua configuration. It does not purchase a game or grant a license to a Steam account.
